## B. LANGKAH INTEGRASI (yang dikerjakan setelah approve)

### B1. Ambil artefak model
- Unduh `jagamata_pitch_tuned_int8.onnx` + `jagamata_pitch_tuned.onnx` + `export_summary.json` dari repo → `ml/export/` (di luar `app/`, sesuai §5.5 butir 5 supaya APK tidak bengkak sebelum siap)
- Salin/letakkan hasil konversi ke `app/src/main/assets/pitch_model.tflite`

### B2. Konversi ONNX → TFLite (Path A)
- Adaptasi `ml/export/convert_pitch_model.py`: tambah arg `--onnx <file>` (lewati tahap `.pt`)
- FP32 → TFLite + dynamic range quantization (target ~1,5–2 MB)
- Verifikasi: `export_summary.json` input/output cocok (input `[1,3,224,224]`, output 3 float)
- **Gagal?** → Path B: tambah dependency `onnxruntime-android`, taruh `.onnx` di assets, implement backend ONNX

### B3. Implement backend pitch
- File baru `app/src/main/java/com/jagamata/app/detection/ModelPitchBackend.kt`:
  - implement `PitchBackend` (kontrak §5.5 tidak berubah)
  - muat model dari assets, preprocess crop 224×224 RGB float32 ImageNet-norm (NCHW)
  - inferensi → ambil `pitch_deg` (index 0) → **negasi tanda** → kembalikan derajat
  - guardrail: `|yaw| ≥ 45°` → kembalikan null (tidak dipakai, lihat rekomendasi laporan)
- `PitchBackendFactory` sudah ada — cukup isi parameternya

### B4. Sambung ke pipeline (face crop)
- `FaceDetectorManager`: simpan frame bitmap terakhir + bounding box wajah → crop → teruskan ke `pitchBackend.pitchDeg(landmarks, faceCrop)`
- Berlaku di mode MediaPipe (landmark) **dan** degraded ML Kit (crop dari `boundingBox`)
- Hasil masuk `DetectionResult.pitchDeg` → state machine (ambang PRD tak berubah)

### B5. Aktifkan flag
- `app/build.gradle.kts`: `buildConfigField("boolean", "USE_TFLITE_PITCH", "true")` (atau `USE_ONNX_PITCH` bila Path B)

### B6. Test
- `ModelPitchBackendTest`: preprocessing (ukuran tensor, normalisasi, NCHW), tanda (negasi), output index 0, model tidak ada → null
- `PitchBackendFactoryTest` (sudah ada) — tambah kasus flag aktif + file ada → backend model
- Pastikan 62 test lama tetap lulus

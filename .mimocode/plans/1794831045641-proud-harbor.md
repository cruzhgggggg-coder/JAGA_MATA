## 1. Buka project
1. Buka Android Studio → **Open** (bukan "New Project") → pilih folder `JagaMataApp`
2. Tunggu **Gradle sync** selesai (pojok kanan bawah, bisa 1–5 menit pertama kali)
   - Kalau diminta SDK → biarkan (sudah ada di `local.properties`)
   - Kalau muncul peringatan versi AGP → update Android Studio ke Ladybug+
3. Kalau sync gagal: **File → Sync Project with Gradle Files**; kalau masih gagal **File → Invalidate Caches → Invalidate and Restart**

## 2. Siapkan device

**Opsi A — HP fisik (disarankan untuk uji deteksi penuh):**
1. Di HP: Settings → About phone → tap **Build number** 7× → Developer options
2. Developer options → aktifkan **USB debugging**
3. Sambungkan kabel USB → di HP pilih **Allow USB debugging**
4. HP muncul di daftar device Android Studio (ikon HP di toolbar)

**Opsi B — Emulator (cukup untuk uji UI/layar):**
1. **Tools → Device Manager → Create Device**
2. Pilih misal **Pixel 6** → Next → sistem image **API 35** (unduh bila diminta) → Finish
3. Tekan ▶ untuk menyalakan emulator
4. Catatan: untuk uji deteksi di emulator, set kamera belakang emulator ke webcam
   (Device Manager → ▶ edit → Show Advanced Settings → Back Camera → Emulated / Webcam)

## 3. Jalankan aplikasi
1. Pilih konfigurasi run **`app`** + device di toolbar
2. Klik tombol **Run ▶** (atau Shift+F10)
3. Pertama kali akan muncul wizard onboarding:
   - **Intro** (3 halaman) → **Pilih usia anak** → **Izin** → **Kalibrasi** → **Selesai**
4. Di layar **Izin**, izinkan satu per satu:
   - **Kamera** → dialog system → Allow
   - **Tampilan di atas aplikasi lain** → dibuka ke Settings system → cari JagaMata → izinkan → kembali ke app
   - **Notifikasi** (HP Android 13+) → Allow
5. **Kalibrasi**: pegang HP ±30 cm dari wajah (bantu penggaris), tahan sampai progres penuh
6. Sampai **Dasbor** → tekan **Mulai** → notifikasi "JagaMata aktif" muncul

## 4. Uji deteksi (penting: kamera BELAKANG)

Karena app memakai **kamera belakang**, wajah harus berada di **depan punggung HP**:

- **Cara termudah:** duduk berhadapan dengan teman/orang di meja — HP di antara kalian, layar menghadap kamu, punggung HP menghadap dia. Wajah dia terdeteksi, kamu lihat hasilnya di layar.
- **Cara sendirian:** letakkan HP menghadap **cermin**, berdiri di depan cermin sehingga pantulan wajah masuk ke kamera belakang.
- **Alternatif emulator:** set back camera emulator ke webcam (lihat §2 Opsi B).

**Yang diamati:**
| Aksi | Yang harus terjadi |
|---|---|
| Wajah ≥50 cm | strip hijau "Aman", angka cm bergerak |
| Wajah 30–50 cm | banner/warn kuning "Waspada" |
| Wajah <30 cm selama ~0,5 dtk | overlay merah **"Ayo mundur dikit!"** + getar |
| Mundur >35 cm selama ~2 dtk | alarm hilang |
| Ruangan gelap (tutup lampu) ~10 dtk | peringatan cahaya |
| Buka app lain (YouTube) saat alarm | overlay tetap tampil di atasnya (K10) |

**Kalau angka cm tidak bergerak / wajah tidak terdeteksi:**
- Pastikan wajah cukup terang dan menghadap kamera belakang
- Cek Logcat (lihat §5) — filter tag `FaceDetectorManager`

## 5. Debugging & lihat log
1. **View → Tool Windows → Logcat**
2. Filter: `package:mine` lalu tambahkan tag:
   - `FaceDetectorManager` — status backend (MediaPipe / "degraded mode" ML Kit)
   - `DetectionFgService` — siklus & penyimpanan data
   - `ModelPitchBackend` — model postur dimuat / gagal
3. **Unit test:** Buka `app/src/test/...` → klik ikon hijau di samping test, atau
   **View → Tool Windows → Gradle → Tasks → verification → test**
   (harusnya **71 test, 0 gagal**)
4. **Lihat UI tanpa device:** klik pratinjau `@Composable` di panel **Split** (kanan editor) — bisa preview Dashboard/Settings dst.

| Gejala | Solusi |
|---|---|
| "Gradle sync failed" | Perbarulu Android Studio (butuh Ladybug+) atau File → Sync ulang |
| "SDK not found" | Pastikan `local.properties` ada `sdk.dir=C:/Users/Zaky/AppData/Local/Android/Sdk` |
| App terbuka tapi tidak ada deteksi | Izin kamera belum dikasih, atau wajah di luar jangkauan kamera belakang |
| Overlay tidak muncul di app lain | Izin "Tampilan di atas aplikasi lain" belum aktif → Settings app → Izin khusus |
